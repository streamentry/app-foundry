# App Foundry — 100 future app ideas

This is an **idea inventory**, not a roadmap or a claim that 100 apps should be built.

- [**CATALOG.md**](CATALOG.md): exactly 100 independent concepts, audience, user job, query hypothesis and provisional score.
- [**SHORTLIST.md**](SHORTLIST.md): ranked top 15, recommended diversified first five and go/stop gates.
- [**EVALUATION.md**](EVALUATION.md): scoring formula, evidence requirements, ASO research and user validation template.

**Existing ten apps are deliberately excluded**: Shift Calendar, Countdown, Medication Checklist, Baby Log, Plant Care, Pet Medication, Mileage Log, Warranty Tracker, Cleaning Schedule, Elderly Routine.

## Portfolio policy

No more than 1–2 new discovery experiments at a time. Don't treat coding speed as proof of product-market fit. Don't submit low-functionality reskins; build a meaningfully distinct user workflow. No apps have been authorized for automatic publishing or monetization.
