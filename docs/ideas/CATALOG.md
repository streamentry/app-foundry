# App Foundry — 100 future utility hypotheses

**Date:** 2026-11-14 · **Status:** idea backlog, NOT validated keyword demand or revenue forecasts.

These 100 ideas **exclude the ten existing app concepts**. Names are working titles, not trademark-cleared brands. Target: independent mobile tools with a clear search query, differentiated job, mostly offline features, limited maintenance, and plausible willingness to pay. Generic clone candidates are penalized.

## How to read

- **Search hypothesis** is an intended query to validate with App Store autocomplete / ASO tooling. **It is not verified search volume.**
- **Score /100** is a directional founder judgment, not an external dataset.
- Start with [the ranked shortlist](SHORTLIST.md), then read [evaluation rubric](EVALUATION.md). 
- Avoid separately shipping apps that are merely re-colored clones. Apple guideline 4.3 requires meaningful differentiation.
