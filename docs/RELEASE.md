# Per-app release checklist

- [ ] App has distinct user value, branding, name, store copy and bundle/package IDs.
- [ ] App Store/Play policies reviewed for copycats, minimum functionality and subscriptions.
- [ ] Device QA on representative iOS and Android OS versions; screen readers, dynamic text, dark mode, offline handling.
- [ ] Crash and purchase flows validated in test environment; restore purchases and cancellations explained when applicable.
- [ ] Privacy policy, privacy labels/data safety form, SDK disclosures, retention/deletion statements accurate.
- [ ] Signing, credentials, EAS project ownership and release permissions checked manually.
- [ ] Store metadata, localization, screenshots, support contact and age rating verified.
- [ ] Monitoring, rollback/incident owner, and post-release experiment metrics documented.
